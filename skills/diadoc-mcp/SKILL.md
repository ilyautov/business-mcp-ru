# Диадок (ЭДО Контура) через MCP

Ставит сервер `diadoc-mcp` из пакета `business-mcp-ru`: 114 методов (чтение 79,
запись 28, необратимое 7), каталог собран из документации
`developer.kontur.ru/doc/diadoc-api`.

## Установка

```json
{
  "mcpServers": {
    "diadoc": {
      "command": "uvx",
      "args": ["--from", "business-mcp-ru", "diadoc-mcp"],
      "env": {
        "DIADOC_CLIENT_ID": "<идентификатор приложения>",
        "DIADOC_TOKEN": "<токен пользователя>"
      }
    }
  }
}
```

## Где взять ключи

1. Идентификатор приложения запрашивается у Контура письмом, для продуктива
   нужна лицензия. Для проб есть тестовый контур.
2. Токен пользователя выдаёт метод `Authenticate` по логину и паролю или по
   сертификату.
3. Оба значения едут в одном заголовке `DiadocAuth`, сервер собирает его сам.

## Типовые задачи

- Показать входящие документы, по которым нужно действие.
- Свести документооборот с контрагентом за период.
- Найти контрагента по ИНН и КПП, проверить, подключён ли он к ЭДО.
- Скачать печатную форму документа.

Подписание и отправка это запись: агент обязан спросить подтверждение, а перед
этим показать, что именно уходит контрагенту.
