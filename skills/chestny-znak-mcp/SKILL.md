# Честный знак (ГИС МТ) и СУЗ через MCP

Ставит сервер `crpt-mcp` из пакета `business-mcp-ru`: 33 метода по кодам
маркировки, заказам на эмиссию, документам и проверке подлинности.

## Честно про источник каталога

Документация ЦРПТ открывается только после входа по КЭП, публичной спеки нет
(`/api/v3/true-api/swagger.json` отдаёт 401). Пути в каталоге взяты из открытых
SDK и помечены `verified: false`. Это карта для разведки: пути надёжные, а
глаголы и параметры надо подтвердить на живом контуре. Сервер показывает этот
статус в `describe_method`, так что агент не выдаст догадку за факт.

## Установка

```json
{
  "mcpServers": {
    "crpt": {
      "command": "uvx",
      "args": ["--from", "business-mcp-ru", "crpt-mcp"],
      "env": { "CRPT_TOKEN": "<токен ГИС МТ>" }
    }
  }
}
```

## Где взять токен

1. `GET /api/v3/true-api/auth/key` отдаёт случайные данные.
2. Данные подписываются КЭП (КриптоПро) на машине пользователя.
3. `POST /api/v3/true-api/auth/simpleSignIn` меняет подпись на токен.

Токен живёт около 10 часов. Подписание идёт вне сервера: закрытый ключ сюда не
попадает и попадать не должен. Никогда не проси у человека сам сертификат или
пароль к контейнеру ключа.

## Типовые задачи

- Проверить коды маркировки пачкой перед приёмкой.
- Посмотреть статус заказа на эмиссию кодов в СУЗ.
- Выгрузить коды, принадлежащие участнику оборота.
- Посмотреть маршрут товара по GTIN.
