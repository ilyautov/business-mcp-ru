# hh.ru через MCP

Ставит сервер `hh-mcp` из пакета `business-mcp-ru`: 133 метода API hh.ru
(чтение 93, запись 31, необратимое 9), каталог собран из официальной спеки
`api.hh.ru/openapi/specification/public`.

## Установка

```bash
uvx --from business-mcp-ru hh-mcp
```

Конфиг клиента (Claude Desktop, Cursor, Claude Code):

```json
{
  "mcpServers": {
    "hh": {
      "command": "uvx",
      "args": ["--from", "business-mcp-ru", "hh-mcp"],
      "env": {
        "HH_TOKEN": "<токен приложения>",
        "HH_APP_NAME": "МоёПриложение (me@example.com)"
      }
    }
  }
}
```

## Где взять токен

1. `dev.hh.ru` → Мои приложения → создать приложение.
2. Скопировать access token.
3. `HH_APP_NAME` заполнить обязательно: hh отклоняет запросы без внятного
   User-Agent, и это первая причина непонятных ошибок 400.

## Что спрашивать у сервера

- `hh_search_methods("отклики на вакансию")` — поиск метода словами.
- `hh_describe_method(...)` — параметры, пагинация, класс доступа.
- `hh_call_method(...)` — вызов. Запись и необратимые действия требуют
  подтверждения, чтение идёт сразу.

## Типовые задачи

- Выгрузить свои вакансии и отклики за период, свести в таблицу.
- Найти вакансии конкурентов по региону и профессии.
- Посмотреть статистику зарплат по роли перед публикацией.
- Ответить кандидатам шаблоном, предварительно показав список человеку.

Не публикуй и не меняй вакансии без явного «да» от человека: это деньги и
репутация работодателя.
