# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-09-11

Первый выпуск. Пять серверов, 698 методов в каталогах.

### Добавлено
- **`hh-mcp`, 133 метода.** Каталог сгенерирован из официальной спеки
  `api.hh.ru/openapi/specification/public`: вакансии, отклики и приглашения,
  резюме, справочники, статистика зарплат, вебхуки.
- **`vk-mcp`, 373 метода.** Каталог собран из официальной схемы
  `VKCOM/vk-api-schema` по бизнес-разделам: товары, сообщества, реклама,
  диалоги, статистика, лид-формы. Разделы для пользователя соцсети (аудио,
  подарки, стикеры) осознанно не включены.
- **`diadoc-mcp`, 114 методов.** Каталог собран из документации
  `developer.kontur.ru/doc/diadoc-api`: документооборот, контрагенты,
  подписание, МЧД, печатные формы, события.
- **`sbis-mcp`, 45 команд.** Каталог собран по справке
  `saby.ru/help/integration/api`. У Saby один HTTP-адрес на все команды, имя
  команды едет в теле JSON-RPC, поэтому в каталоге оно лежит отдельным полем.
- **`crpt-mcp`, 33 метода.** ГИС МТ и СУЗ. Документация ЦРПТ за КЭП, публичной
  спеки нет, поэтому пути взяты из открытых SDK и помечены `verified: false`.
- Класс доступа (чтение, запись, необратимое) у каждого метода, перед записью
  агент обязан спросить подтверждение.
- Список разрешённых доменов у каждого сервера: заголовок авторизации не
  покидает домен сервиса даже при вызове произвольного пути.
- 30 тестов на каталоги: уникальность идентификаторов, допустимые классы
  доступа, хосты внутри allowlist, непустые описания, соответствие чисел в
  README реальным каталогам.
